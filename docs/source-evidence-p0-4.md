# 第四批来源定位与东吴武昌点位纠错 P0

日期：2026-09-23。本批复核正在收口的证据定位改动，修正一条会把三国吴都显示到错误城市的点位，并提高同页王表引用的可复核性。点位仍只作浏览定位，不表示古城边界或政权疆域。

## 东吴武昌

旧 `geo-eastern-wu-wuchang` 坐标位于今天武汉市武昌区附近，误把同名的现代地名当成孙权时期的武昌。湖北省文化和旅游厅[《鄂吴名都鄂州（武昌）》](https://wlt.hubei.gov.cn/bmdt/ztzl/zshb/201912/t20191226_1799420.shtml)明确将吴都武昌置于今鄂州，记载孙权221年迁鄂、229年迁建业及孙皓265年再次迁都。[鄂州市人民政府的专题文章](https://www.ezhou.gov.cn/zjez/ezrw/ezss/202205/t20220526_469968.html)记载孙皓于266年12月还都建业。[联合国地名专家组城市资料](https://ungegn.un.org/dashboard/cities/details?id=2006)给出现代鄂州坐标 30.4°N、114.88°E，来源为中国地名研究所。

点位现用该现代城市坐标作为 `approximate` 区域锚点；适用期改为222—229年、265—266年。221年早于本数据集东吴政权采用的222年起点，因此按政权存续期裁切。229年迁都与265—266年复都按闭区间保留交接年，不表示全年唯一中心。湖北省文旅厅表格将第二段终年写作267年；本批采用鄂州市政府文章的266年12月还都口径，在记录中保留差异说明。

## 王表与维护元数据

拜占庭帝国96位人物、99条任期及高丽34位人物、34条任期原共用“对应姓名行”定位文本。现有 `locator` 逐条写明具名王表条目；高丽同名的两位定宗再用表格序号区别。来源等级仍维持原有三级分类，增加定位并不自动提高史料等级。

第三批新增的 OSM 坐标引用注明2026-09-16检索，共享来源的 `accessedAt` 已同步至该日期；测试防止来源访问日期早于引用中的检索日期。12条新增坐标说明中的不通顺措辞也已修正。

此批新增3项来源，未增加政权或点位。原100条基线点位证据账本现有42条已核实、58条待查；194条生产点位中82条全部引用已定位、54条部分定位、58条完全无定位。无定位预算同步收紧至58，待查记录继续保留具体缺口，不以通用首页或政权纪年充当点位证据。
