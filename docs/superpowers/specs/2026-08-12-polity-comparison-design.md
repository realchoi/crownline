# 双政权时间对比设计

日期：2026-08-12

## 目标

在现有全览、时间点、地区、搜索、类别和详情浏览之上，允许用户选择两个真实政权并比较存在区间、共同存续时间及相关统治者。对比状态同步到 URL，刷新与分享后可恢复。

## 交互设计

时间轴行和时间点政权卡片提供独立的“加入对比”按钮，原有时间条或卡片点击继续打开详情。历史分期不参与政权对比。

选择规则如下：

- 未选中时点击“加入对比”追加到末尾；
- 已选中时点击“移出对比”移除该政权；
- 最多选择两个政权；已有两个时，其他政权的加入按钮禁用；
- 对比台提供单项移除与全部清除；
- 第一个政权选中后显示空槽和继续选择提示；
- 第二个政权选中后展开完整对比结果。

选择顺序具有左右语义，通过重复查询参数保存：

```text
?compare=polity-cn-tang&compare=polity-byzantine-empire
```

URL 恢复时只接受当前索引中存在的真实政权 ID，去重并保留前两个；未知 ID、历史分期 ID 与多余值被清洗。

## 时间计算

领域层新增纯函数，对双方一个或多个闭区间做集合求交。计算统一使用压缩公元 0 年的历史序数，因此公元前 1 年与公元 1 年连续。

输出包含：

- 零个、一个或多个共同存在区间；
- 共同存续总年数，按闭区间逐段累加；
- 当前年份是否位于任一共同区间。

交集边界继承实际决定边界的原始日期精度；双方边界年份相同时采用更保守的精度，避免把约年提升为精确年份。

## 对比内容

双方并列展示名称、政权形态、地区、完整存在区间与校订状态。中间摘要展示：

- 有交集：共同存在区间和累计年数；
- 无交集：明确显示“存续时间没有重叠”，不推断双方没有历史关系；
- 当前时间点位于交集：突出当前年份，并分别展示双方当年统治者状态；
- 当前时间点不在交集：不展示隐藏年份的统治者快照。

双方详情包加载完成后，按共同存在区间筛选任期，展示“共同存续期内已收录统治者”数量与可展开名单。名单保留统治、共治、摄政与争位角色，任期只展示落在共同区间内的部分。

## 数据加载与错误处理

对比台复用现有 `CrownlineDetailLoader`，并行加载两个详情包。成功结果由现有 loader 缓存。选择变化或组件卸载后忽略迟到结果。

- 加载中：基本时间对比立即可见，统治者区域显示加载状态；
- 单方失败或详情缺失：明确指出对应政权，并提供统一重试按钮；
- 时间交集计算不依赖详情包，详情失败不会隐藏基本比较；
- 不在阶段 4A 展示 `relationships`，无交集也不等于没有关系。

## 组件与文件边界

- `src/domain/polityComparison.ts`：区间求交、共同年数与共同期统治者选择；
- `src/domain/browseState.ts`：对比 ID 的 URL 清洗和序列化；
- `src/components/ComparisonToggle.tsx`：可复用的加入/移出按钮；
- `src/components/ComparisonPanel.tsx`：选择槽、时间摘要、双方列、统治者与加载状态；
- `TimelineStage.tsx` / `TimepointView.tsx`：注入对比状态与独立按钮；
- `App.tsx`：组合对比状态、实体和 loader，不承载区间算法。

保持现有字体、色彩、纸张纹理、边框和响应式语言。桌面使用两列档案卡片，手机降为单列；对比按钮必须有 `aria-pressed` 或等价可访问状态，加载与错误使用明确 live region。

## 测试与验收

按 TDD 覆盖：

1. 无交集、单段交集、多段交集、闭区间边界和跨公元前后；
2. 相同年份边界采用更保守精度；
3. 共同存续期统治者过滤与任期裁剪；
4. URL 对比 ID 去重、清洗、顺序保持与默认省略；
5. 全览和时间点均可加入、移除与清空；
6. 历史分期没有加入控件，满两个后其他按钮禁用；
7. 两个政权展示交集、共同年数和共同期统治者；
8. 当前年份落入交集时展示双方当年统治者；
9. 详情加载失败可重试，迟到请求不污染新选择；
10. 手机布局、键盘与焦点路径无回归。

完成前运行：

```bash
npm run validate:data
npm test
./node_modules/.bin/vite build
npm run check:fonts
```

按用户 2026-08-12 的最新指示，本阶段不安装新依赖，也不执行 TypeScript 静态检查；直接使用仓库已有的 Vite 二进制验证生产打包。

## 非目标

- 不新增结构化历史关系生产数据；
- 不实现地图或疆域重叠；
- 不允许历史分期参与对比；
- 不修改数据契约、schema、依赖或 CI；
- 不执行 commit、push、PR 或远程部署。
