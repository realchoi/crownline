# 阶段 2B：多地区完整全览时间轴设计

## 背景与目标

阶段 2 已让中国、自选地区和全球已收录三种范围参与时间点查询，但全览模式仍强制回退为中国范围，且现有时间轴只会渲染中国七个历史分期中的实体。阶段 2B 要让相同的地区状态也用于全览模式，使自选地区和全球已收录可以浏览当前数据集的完整年代范围，同时保持中国全览的既有可读性。

本阶段不补充新的历史实体或史料，不改变数据契约，也不把“全球已收录”表述为完整世界史。

## 方案选择

采用混合分组与局部尺度方案：

- 中国范围继续使用已有七个历史分期及各自的局部时间尺度。
- 自选地区与全球已收录按顶层历史地区生成时间轴分组，每组按组内实体的实际年代范围建立局部尺度。
- 同时属于两个或更多当前可见地区的政权进入独立“跨地区政权”组，不在各地区组中重复出现。
- 未收录地区不产生空时间轴组；覆盖说明继续明确区分未收录、样本覆盖和历史上不存在。

未采用以下方案：

1. 所有地区共用从最早到最晚的一条全局尺度。该方案便于直接比较绝对年代，但约四千年的跨度会让短暂政权缩成不可读的点。
2. 跨地区政权在每个所属地区重复展示。该方案的地区归属更直观，但违反“同一实体只显示一次”的验收要求，也会让结果数量和详情入口产生歧义。

## 状态与 URL

`BrowseState.regionScope` 不再因切换到全览模式而重置。中国仍是默认范围，因此默认 URL 不写 `scope`；自选地区和全球已收录在全览与时间点模式下都使用现有 `scope` 与重复 `region` 参数。

示例：

```text
/?scope=global
/?scope=custom&region=region-europe&region=region-west-asia
/?mode=point&year=1000&scope=global
```

读取 URL 时，地区参数不再依赖浏览模式。非法地区 ID 继续被清洗；没有有效地区的自选范围继续回退到中国。全览与时间点切换只改变 `mode`，地区选择保持不变。

## 结果选择与分组

统一选择器继续负责地区、搜索、类别和可选年份的组合筛选，且从 `data.entities` 独立检索，不依赖 `timelineSections`。

新增纯领域分组逻辑，把全览命中结果转换为渲染组：

```ts
interface OverviewTimelineGroup {
  id: string;
  title: string;
  displayRange: string;
  range: { startYear: number; endYear: number };
  matches: MatchedEntity[];
  regionId?: string;
  kind: "china-section" | "region" | "cross-region";
}
```

分组规则如下：

1. 中国范围直接复用已有 `timelineSections`，保持当前阶段顺序、条目顺序和标题。
2. 自选与全球范围先求当前范围内可见的顶层历史地区。中国实体归入“东亚”，外部实体归入南亚、西亚、欧洲、北非等顶层地区。
3. 一个实体若只命中一个可见顶层地区，归入该地区组。
4. 一个实体若命中两个或更多可见顶层地区，归入“跨地区政权”组且仅出现一次。
5. 组内实体按最早存在年份、最晚存在年份、中文主名称稳定排序；搜索和类别筛选只减少组内条目，不改变剩余条目的相对顺序。
6. 地区组按 `data.regions` 中的顶层历史地区顺序展示；跨地区组置于普通地区组之前，便于解释去重行为。
7. 每个动态组的范围取组内全部存在区间的最早起点和最晚终点。只有一个年份时使用安全的最小跨度，避免除零。

历史分期仍只随中国数据出现。中国范围保留原有历史分期；多地区范围中若历史分期命中某个地区，也按同一归属规则进入相应组，不构造其他地区不存在的数据。

## 界面与交互

地区范围控件在全览和时间点模式都显示，并共享同一份受控状态。全览模式保持类别图例；年份控件仍只在时间点模式显示。

多地区全览的每个组复用现有时间轴卡片、坐标轴、条目标签、时间条、详情按钮和键盘焦点行为。动态组标题显示地区名称或“跨地区政权”，副标题显示该组的完整年代范围。跨地区组中的条目标签额外显示当前范围内的地区名称，普通地区组不重复显示组名。

短暂政权继续使用最小可点击宽度；多段存在区间继续绘制多个时间条，但所有时间条打开同一实体详情。手机端继续使用现有两列时间轴布局，并允许名称和年代省略显示，不引入横向滚动。

结果摘要按当前范围计算：显示命中实体数、当前可见分组数和范围名称，不再用中国 `timelineSections` 的实体总数衡量全球或自选范围。中国默认状态继续保留“73 / 73 个条目，涉及 7 个历史阶段”的现有文案，以避免回归。

## 空状态与覆盖提示

全览无结果时区分两类情况：

- 当前所选地区没有任何已收录政权：提示“尚未收录代表性政权”，不使用“历史上不存在”。
- 当前范围原本有数据，但被搜索或类别筛选清空：提示调整搜索或类别。

“全球已收录”和外部地区继续展示覆盖有限说明。中国范围继续展示现有通史口径说明；自选与全球范围展示阶段 2 已有的样本覆盖说明。

## 文件边界

- `src/domain/browseState.ts`：让地区状态跨浏览模式读取、写入并保持。
- `src/domain/overviewTimeline.ts`：新增纯分组、排序、组范围和展示范围计算，不包含 React。
- `src/components/FilterPanel.tsx`：让地区控件在两种浏览模式下可用，并调整布局说明。
- `src/components/Timeline.tsx`：根据中国范围或动态多地区组选择渲染策略和空状态。
- `src/components/TimelineStage.tsx`：接受通用时间轴组，并为跨地区条目展示地区辅助信息。
- `src/app/App.tsx`：移除全览强制中国逻辑，保持模式切换时的地区状态，更新统计与覆盖文案。
- `src/styles/styles.css`：增加多地区组、地区辅助标签和两种模式下地区控件的响应式样式。
- `tests/*.test.ts(x)`：覆盖分组去重、排序、局部尺度、URL 恢复、模式切换和界面空状态。
- `README.md`、`ROADMAP.md`：同步阶段 2B 的功能与完成记录。

## 验证策略

领域测试覆盖：

- 欧洲与西亚同时选择时，拜占庭帝国只进入跨地区组一次。
- 西亚与北非同时选择时，阿拔斯哈里发只显示一次。
- 单选欧洲时，拜占庭帝国与神圣罗马帝国同属欧洲组。
- 全球范围生成东亚、南亚、欧洲等动态组，并为每组计算自身年代范围。
- 搜索、类别和地区组合后不产生空组。
- 单年份测试数据不会导致无穷或非数字坐标。

状态与界面测试覆盖：

- `/?scope=global` 可直接恢复全球全览。
- 自选地区在全览与时间点切换后保持，URL 参数不丢失。
- 全球全览能看到四个外部代表条目，中国全览仍显示 73 个条目与七个阶段。
- 多地区实体只有一个可访问的条目行，但多段存在区间仍可有多个详情按钮。
- 未收录地区全览显示资料缺口提示，不声称历史上不存在。

最终执行 `npm run validate:data`、`npm test`、`npm run typecheck` 和 `npm run build`，并在桌面、窄屏、浅色与深色模式下检查时间轴布局。

## 非目标

- 不新增或补齐全球历史数据。
- 不修改 JSON Schema、共享数据契约或现有实体 ID。
- 不提供统一全局缩放、拖拽、缩放或虚拟滚动。
- 不引入路由库、状态管理库或新的运行时依赖。
- 不改变时间点模式的年份判定与历史分期分区规则。
