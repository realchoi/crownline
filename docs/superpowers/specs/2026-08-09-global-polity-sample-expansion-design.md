# 全球政权均衡补样设计

日期：2026-08-09

## 目标

在不改变现有时间轴、地区筛选、时间点浏览和详情懒加载架构的前提下，补充全球其他地区的代表性政权，使“全球已收录”从中国加四个世界样本扩展为分布更均衡的世界历史样本。

本次首批新增约 16 个政权，覆盖东亚、东南亚、中亚、南亚、西亚、欧洲、非洲和美洲八个板块。所有新增政权均按现有世界条目的深度补齐：政权简介、存在区间、年代口径、地区、来源、统治者和任期。

“全球已收录”仍表示当前数据集中的全部内容，不表示世界历史已经完整覆盖。

## 范围

### 新增政权

首批条目如下：

| 板块 | 政权 |
| --- | --- |
| 东亚（中国之外） | 高丽、德川幕府 |
| 东南亚 | 高棉帝国、满者伯夷 |
| 中亚 | 贵霜帝国、帖木儿帝国 |
| 南亚 | 孔雀帝国、莫卧儿帝国 |
| 西亚 | 塞尔柱帝国、奥斯曼帝国 |
| 欧洲 | 法兰克王国、英格兰王国 |
| 非洲 | 法蒂玛王朝、马里帝国 |
| 美洲 | 阿兹特克帝国、印加帝国 |

高丽与德川幕府归入现有 `region-east-asia`；法蒂玛王朝归入现有 `region-north-africa`；阿兹特克帝国与印加帝国归入现有 `region-americas`。

### 新增地区

新增以下历史地区记录：

- `region-southeast-asia`：东南亚；
- `region-central-asia`：中亚；
- `region-west-africa`：西非。

新增地区使用 `historical-region`，不代表现代主权边界。覆盖状态统一使用 `sample`，并在 `coverage.note` 中说明当前仅为代表性条目。

本次不新增世界历史分期，也不把新增政权强行挂入中国历史阶段。世界全览继续由实体集合动态分组，按地区显示并对跨地区实体去重。

## 数据设计

### 政权实体

每个政权继续使用独立的 `src/data/source/entities/world/<entity-id>.json` 分片，遵守当前全局 ID 命名空间和 `order` 稳定排序约定。实体至少包含：

- 常用中文主名、英文别名和本地名；
- `polityForms`、`displayCategory` 和历史地区；
- 一个或多个包含端点的 `existencePeriods`；
- `chronologyStatus`、`confidence`、`chronologyNote`；
- 简介与来源引用。

中断、复立或存在多个历史口径的政权使用多个区间或 `alternativeChronologies`，不把不连续时期压成单一连续区间。

### 统治者与任期

统治者和任期继续内嵌在政权分片中，由现有生成器提取到详情闭包。优先录入主要统治者完整序列；共治者、摄政者和主要争位者按现有角色字段单独标注。普通任期空档不推导为无人统治，只有有来源支持的明确空位才写入 `reignVacancies`。

所有人物和任期记录至少关联一条来源。早期政权的年代或人物若无法达到同等确定度，保留精度、争议和资料缺口说明，不伪造精确年份。

### 来源策略

关键年代、政权沿革和统治者年表优先使用博物馆、大学、国家机构或学术参考资料；百科资料用于辅助核对和补充常用别名。来源以稳定 ID 写入 `src/data/source/sources/sources.json`，实体、人物、任期和替代年代口径均通过 `sourceRefs` 关联。

## 应用行为

不重做 React 页面结构。现有地区选择器、全览分组、时间点筛选、URL 状态和详情懒加载自动消费新增数据。

- 地区选择器展示新增地区，并标注“覆盖有限”；
- 全球范围包含全部新增政权；
- 多地区全览按地区分组，跨地区政权只显示一次；
- 时间点模式仅在政权存在的年份显示该政权；
- 详情根据当前年份显示对应统治者、共治者、摄政者、争位者或资料缺口；
- 美洲从 `none` 变为 `sample`，不再触发“尚未收录地区”的提示；
- 空结果继续区分未收录、覆盖有限但当前年份无条目和被搜索/类别筛选为空。

## 校验与测试

数据层继续使用 JSON Schema 和 TypeScript 语义校验，重点验证：

- 新增实体、人物、任期、地区和来源 ID 无重复；
- 地区、来源和任期引用无悬空；
- 存在区间、任期和明确空位的边界合法；
- 政权形态、展示类别和实体类型一致；
- 16 个政权均能生成详情闭包；
- 新地区覆盖状态和说明完整。

补充或更新回归测试，覆盖全球范围、自选地区、URL 恢复、多地区分组与去重、时间点筛选、统治者状态和现有中国/四个世界条目的不回归。

完成前运行：

```bash
npm run validate:data
npm test
npm run typecheck
npm run build
npm run check:fonts
```

## 验收标准

1. 16 个新增政权在全球范围和对应地区范围中可见。
2. 每个新增政权均可打开详情，并能加载统治者、任期和来源闭包。
3. 时间点模式能按存在区间显示或隐藏政权，并正确展示统治者状态或资料缺口。
4. 全球全览按地区分组，跨地区条目不重复。
5. 美洲覆盖状态从未收录变为覆盖有限，提示文案不再误导。
6. 现有中国数据、四个世界样本、地区 URL 状态和时间轴行为无回归。
7. 所有质量命令完成且无新增数据校验、类型检查、测试、构建或字体缺字错误。

## 非目标

- 本次不追求各地区完整通史覆盖；
- 不新增地图、疆域快照、政权关系或新的视图模式；
- 不重构既有数据分片目录或 React 组件边界；
- 不把现代国家边界套用于历史政权；
- 不从无资料的任期空档推断历史结论。
