# 阿拔斯哈里发萨迈拉分期点位审查

日期：2026-09-23。本批针对覆盖报告中阿拔斯哈里发836—892年的地理年份缺口，只补有直接来源支持的第二都城点位；750—761年继续标为尚无可展示点位，不据政权起点推定都城。

## 采用口径

[UNESCO 世界遗产中心《Samarra Archaeological City》](https://whc.unesco.org/en/list/276)的“Outstanding Universal Value”明确将萨迈拉列为阿拔斯哈里发国继巴格达后的第二都城，年代为836—892年。[遗产地地理数据](https://whc.unesco.org/en/list/276/maps/)将 `276rev-002 Samarra Centre Zone` 登记为北纬34°13′34.59″、东经43°52′57.26″，换算为34.226275、43.882572。此坐标仅作古城中心区的近似浏览锚点，不代表宫殿位置、考古边界或政权疆域。

原巴格达点位仍为762—835年与893—1258年两段；萨迈拉新增836—892年，与巴格达记录不互相外推。新点位令阿拔斯有点位的政权年由440/509增至497/509，未知年份由69降至12，剩余750—761年。全数据集地理覆盖增加57个政权年，统计只表示该年有可展示点位。

本批新增1条地理快照和2项可定位来源。来源及坐标单独登记在维护数据中；回归测试检查835/836与892/893两个分期边界、早期未知状态、坐标精度和来源闭包。
