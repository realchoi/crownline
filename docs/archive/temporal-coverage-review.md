# 按年份的资料覆盖与首批地理校订

日期：2026-09-07。工具侧覆盖报告升级到 v3，浏览器 Schema 保持 v5。逐政权是否有记录的既有覆盖指标继续保留，新 `temporalCoverage` 用于识别指定年份的资料缺口。

## 计算口径

区间以 `{startYear, endYear}` 表达源数据采用年代下的闭区间，不存在公元 0 年；共治、重复点位和同年迁都不会重复计数。按存在期裁切和求并集，中断年份不进入分母。约年及争议年代仍按已采用端点计算，这些比例不是精确历史事实或史料可信度评分。

- `rulerPeriods` / `rulerCoveredYears`：仅 `ruler` 和 `co-ruler`。
- `regencyPeriods`、`claimantPeriods`：分别保留摄政和争位资料。
- `anyReignPeriods` / `anyReignYears`：全部任期角色的并集，仅表示有任期类记录。
- `explicitVacancyPeriods`：仅有来源的明确空位。
- `documentedYears`：正式统治者/共治任期与明确空位的并集。
- `rulerDetails.unknownPeriods`：存续期扣除上述正式任期和明确空位；摄政/争位记录不能单独消除此未知状态。未知不表示无人统治。
- `geography.coveredPeriods/unknownPeriods`：有适用点位及尚无适用点位的区间；不表示控制范围。

报告按实体 ID 稳定排序，纯计算位于 `src/domain/temporalCoverage.ts`。跨政权汇总分母是“政权年”：两个同时存在的政权各计自己的年份，不是全球不重复年份。报告和证据审查元数据均不进入浏览器数据包。

后三者的保留缺口不是“史料无法恢复”的最终结论。本批只修改三政权的四条点位记录（新增三条，修改一条），增加26个有点位的政权年。地图仍有年份缺口的政权由25个降至24个；这不是全球地理史的完成率。统治者任期未新增，已有夏、大津巴布韦、特奥蒂瓦坎的审查结论保持不变。

## 来源与采用边界

[甘肃文博局转载屈直敏《西凉王李暠对敦煌酒泉的经营》](https://www.gswbj.gov.cn/a/2023/02/16/16474.html)第一节支持400年定都敦煌及405年迁都酒泉，第三节末段支持420年酒泉失守、李恂重入敦煌及421年败亡。转折年按“年内曾存在”口径可以同时有两个点位。

[福州市方志委《福州建置沿革》](https://www.fuzhou.gov.cn/zgfzzt/zjrc/qhyg/202509/t20250925_5083026.htm)的清代段落支持1645年隆武政权在福州称帝及1646年福州府恢复。本批只对应隆武阶段，不把福州标成整个南明时期的唯一首都。

[朝阳市政府《朝阳三燕文化概述》](https://chaoyang.gov.cn/html/CYSZF/202105/0162104991559956.html)“一、三燕王朝的历史”支持350年迁蓟、357年迁邺；本条只采用这两项迁都信息，不采用文章其他人物生卒表述。[北京市历史文化名城保护规划](https://fgw.beijing.gov.cn/fgwzwgk/2024zcwj/ghjhwb/wngh/202003/t20200331_3739269.htm)将蓟城定位于今广安门一带。

现代区域参照来自 GeoNames 的独立记录：[福州1810821](https://www.geonames.org/1810821/fuzhou.html)、[酒泉1279945](https://www.geonames.org/1279945/jiuquan.html)、[敦煌1529531](https://www.geonames.org/1529531/dunhuang.html)、[广安门桥6268990](https://www.geonames.org/6268990/guang-anmen-qiao.html)。后面三项同时从官方搜索页面核对记录 ID 和经纬度。广安门桥仅作蓟城所在区域的浏览参照，不声称桥梁是古城遗址；其坐标四舍五入至小数点后五位。各点统一 `regional` 精度，不表示宫殿、考古边界或疆域。GeoNames 采用 CC BY 4.0，记录保留署名与来源。
