## 结果

闭环记录包括洛阳3条、开封4条、成都3条与姑臧2条。坐标分别定位到OSM的洛阳市关系、开封城市节点、成都市关系和武威城市节点；这些现代对象继续只作区域浏览锚点，不表示古城边界或政权疆域。

部分定位点位预算由66收紧到54。后续新增未定位引用，或证据改善后没有同步收紧预算，都会使 `npm run check:evidence` 失败。
