# 第二批来源定位 P0

日期：2026-09-15。本批继续处理地图证据，并首次把“部分定位记录”纳入非回归门禁。

## 结果

| 指标 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 完全无定位点位 | 67 | 59 |
| 部分定位点位 | 70 | 66 |
| 全部引用已定位点位 | 57 | 69 |

本批闭环巴格达、尼西亚、德里、贡德尔、埃迪尔内、大不里士、加兹温与哈兰八条原无定位记录；同时为刘宋、南齐、梁、陈的建康点位补齐南京具体坐标记录。

## 语义校正

- 巴格达拆为762—835与893—1258两段，836—892年的萨迈拉首都期保持未知。
- 贡德尔起点由1632年改为UNESCO直接支持的1636年。
- 尼西亚终点由1260年改为恢复君士坦丁堡的1261年，交接年允许并列。
- 德里改为全时期“代表性中心”，不再把多个苏丹王朝及城址压成一个固定首都点。

这些处理使地理覆盖率由87.51%降至87.31%。下降来自证据边界收窄，不是数据退化；61个新增未知政权年继续明确表示尚无可安全采用的连续点位。

## 门禁

完全无定位点位预算收紧到59条，部分定位点位预算新增并固定为66条。任何一项增加，或改善后没有同步收紧预算，都会使 `npm run check:evidence` 失败。
