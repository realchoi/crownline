# 第二批分期地图点位审查

日期：2026-09-08。本审查接续[按年份的资料覆盖与首批地理校订](temporal-coverage-review.md)，只处理前燕、南明、西秦与神圣罗马帝国的既有点位年份缺口。地图点位仍只表示在所列年份内有直接证据支持的都城、政治中心或帝国机构驻地；迁都年两端均按“年内曾存在”显示，不表示全年唯一中心。

本批新增13条地理快照、15项来源，增加206个有点位的政权年。这里的“覆盖”只表示指定年份至少有一个可展示点位；它不表示迁都史、宫廷行程或多中心结构已经穷尽，也不是领土覆盖率。

## 前燕

[朝阳市人民政府《朝阳三燕文化概述》](https://chaoyang.gov.cn/html/CYSZF/202105/0162104991559956.html)直接记载337年慕容皝在棘城称燕王、342年迁龙城、357年由蓟迁邺、370年邺城失守。[中国古都学会的邺城遗址资料](https://gdmc.snnu.edu.cn/info/1005/1140.htm)另将前燕在邺的国都期明确列为357—370年，并将遗址定位在临漳县西南。

棘城确切位置仍有不同考证。本批采用朝阳市政府所述“今北票市章吉营子乡”口径，坐标只取[NGA GNS 的 Zhangjiying 现代聚落记录](https://geographic.org/geographic_names/name.php?c=china&fid=1131&uni=-2705507)作 `regional` 锚点，并在记录中披露不同考证。邺城采用[Wikidata Q1274372](https://www.wikidata.org/wiki/Q1274372)的遗址坐标作 `approximate` 定位。两点均不把单一坐标解释为古城边界或宫城位置。

## 南明

永历朝廷频繁播迁，本批没有把某一城市扩展成整个永历时期的固定首都。

- [临桂区政协地方文史资料](https://www.lgzx.gov.cn/a/5c3610c69490c)支持1647年二月抵桂林、同年继续迁往武冈和柳州。本批只用桂林表示该年可核验的临时朝廷驻地，不声称全年唯一驻地。
- [湖北省档案馆“援剿总兵关防”](https://www.hbda.gov.cn/info/2436.jspx)支持1649年迁至南宁、1651年四月仍在南宁制印且尚未进入黔滇，以及1652年迁安龙。
- [贵州省政协文史资料](https://www.gzszx.gov.cn/gzzxb/web/doc/detail/2205/A3)支持1652年迁都安龙、1656年由安龙赴昆明及1659年春离昆明入缅。它也记载1661年冬被引渡回昆明、1662年被杀；这两项属于拘押和处死，不足以把昆明延长为南明政治中心。

现代坐标统一来自 GeoNames 的[Guilin 1809498](https://www.geonames.org/1809498/)、[Nanning 1799869](https://www.geonames.org/1799869/nanning.html)、[Anlong 1818019](https://www.geonames.org/1818019/)与[Kunming 1804651](https://www.geonames.org/1804651/kunming.html)，均降为城市区域定位。

1648年资料反映朝廷在湖南、两广间继续移动，但本批没有取得足以划定连续政治中心区间的机构来源；1660—1662年处于缅甸流亡、被引渡与拘押阶段，也没有把现代缅甸城市或昆明刑死地点写成政权中心。四年继续保留为资料缺口，含义仍是“尚无本批采用的可展示点位”。

## 西秦

西秦必须按两次建国和末期迁徙拆分，不能把一个中心跨过400年灭国与409年复国。

- [甘肃官方西秦专题](https://ydyl.gansu.gov.cn/gsydyl/gjjl/whsl/202312/t20231228_16374.html)与[《兰州市志·建置区划志》](https://www.gsdfszw.org.cn/gssz_58/dyl_69/lzs_224/dyjjzqhz/201707/P020170705359528515080.pdf)支持385年筑勇士城为都、388年迁金城；后者的大事辑要又明确395年复迁苑川、400年后秦攻占。
- [《榆中县志》大事记](https://www.gsdfszw.org.cn/gsxz/lzs_266/yzx/201708/P020170814560773151422.pdf)支持409年复国复都苑川及412年迁枹罕；甘肃专题同时记录409年复国过程中乾归由枹罕率众移居度坚山。因此409年显示度坚山与苑川两个有来源的年内中心。
- [《临夏回族自治州志》大事记](https://www.gsdfszw.org.cn/gssz_58/dyl_69/lxhzzzz_236/201707/P020170706385934821639.pdf)支持412年先迁谭郊、再迁枹罕，并明确429年暮末迁保定连、相国元基仍守枹罕。本批据此把枹罕止于429年，没有顺着政权终年外推到431年。保定连虽能确认名称和大致在临夏地区，本批未获得足以区别于枹罕区域锚点的可靠现代定位，因此不另造重合点位。
- [《资治通鉴》卷一百二十一](https://ctext.org/wiki.pl?chapter=527046&if=gb)明确记载430年暮末东行受阻后“留保南安”、故地入吐谷浑及431年南安失守。[《陇西县志》](https://www.gsdfszw.org.cn/gsxz/dxs_276/lxx/201708/P020171123344608501916.pdf)把南安郡治定位于今陇西县东南，并记431年南安为夏所夺。

苑川、勇士城使用 GeoNames [Yuzhong 1785532](https://www.geonames.org/1785532/)作区域锚点，度坚山使用[Jingyuan 1805547](https://www.geonames.org/1805547/)，谭郊与枹罕使用[Linxia 1803331](https://www.geonames.org/1803331/)，南安使用[Longxi 1802304](https://www.geonames.org/1802304/)。这些坐标都只是现代城市或县域中的 `regional` 参照；古城、山地营地与郡治位置没有被升级成精确遗址。

最终点位分段为勇士城385—388、金城388—395、苑川395—400、度坚山409、苑川409—412、谭郊412、枹罕412—429、南安430—431。迁都年可显示两个或多个点；401—408没有任何西秦点位。

## 神圣罗马帝国专题审查

[deutschland.de 的德国史资料](https://www.deutschland.de/de/deutsche-geschichte-bis-1945)明确说明神圣罗马帝国中世纪没有固定首都，君主携家族与宫廷巡行，并以各地行宫作为临时政府驻地。因此既有亚琛点位仍只适用于962—1024，本批不把它外推到萨利安、霍亨斯陶芬或后来的帝国阶段。

本批也审查了布拉格、维也纳等皇帝或哈布斯堡宫廷驻地材料。相关材料常同时涉及波希米亚王权、奥地利世袭领地与哈布斯堡复合君主国，不能仅凭王朝宫廷所在地把整段神圣罗马帝国写成单一中心；这些候选暂不进入生产数据。

[雷根斯堡市“document Reichstag”](https://www.regensburg.de/museen/die-museen/documente/document-reichstag)则直接支持1663—1806年永久帝国议会持续在旧市政厅开会，并说明帝国等级及欧洲使节在此处理政治事务。因此新增 `political-center` 点位，坐标取 GeoNames [Regensburg 2849483](https://www.geonames.org/2849483/regensburg.html)。记录明确说明它是常驻帝国议会所在地，不是固定皇都，也不表示皇帝宫廷持续驻此。

1025—1662继续保留为专题缺口。这个结论不是说该时期没有政治中心，而是现有模型尚未把巡回宫廷、帝国议会、帝国法院、选举与加冕地点及不同王朝驻地拆成可稳定映射的事件或分期记录。
