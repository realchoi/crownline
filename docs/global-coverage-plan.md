# 全球政权覆盖矩阵与扩充顺序

本文件说明如何使用 `.generated/data/coverage-report.json` 中的 `globalCoverageMatrix` 规划数据扩充。矩阵按顶层历史地区与六个时代段统计存在区间相交的已收录政权；跨地区政权会进入其绑定的每个地区。

矩阵只描述当前数据集，空格不表示历史上没有政权，低计数也不等于该地区历史活动较少。它的用途是防止仅按知名度追加条目，造成地区或时代集中。

## 扩充优先级

1. 优先补齐西亚、欧洲和北非的古代断层，候选应形成连续脉络，而不是孤立增加知名条目。
2. 补充东亚以外地区的前1000年以前与前1000—前1年样本，并保留年代争议与考古证据边界。
3. 补齐西非、东非与南部非洲在1000年以前的断层；不能把后世王表倒推为早期精确任期。
4. 为东南亚、中亚和美洲补充能连接现有样本前后阶段的政权，避免只扩充同一世纪。
5. 新增顶层地区前，先评估中部非洲与大洋洲的地区模型、资料可得性和中文命名口径。

## 每批验收

- 说明该批填补的地区和时代格，而不是只报告新增总数。
- 每个政权具备存在区间、地区、来源和可信度说明；不能为追求矩阵非零而虚构记录。
- 统治者与地理数据分别报告逐年覆盖，代表序列不得写成完整王表。
- 来源定位缺口不得超过 `npm run check:evidence` 的非回归预算；改善后同步收紧预算。
- 运行数据生成、完整校验、文档、字体及相关测试。
